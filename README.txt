MEIN DEPOT – iPhone-Web-App

Dateien:
- index.html: Dashboard
- manifest.json: Web-App-Metadaten
- service-worker.js: Offline-Grundgerüst

WICHTIG:
1. Das Paket ist ein Web-App-Prototyp, keine native iOS-App und keine Handels-App.
2. Für „Zum Home-Bildschirm“ muss es unter einer HTTPS-Adresse veröffentlicht werden.
3. Das Kursdiagramm wird von TradingView eingebettet. Verfügbarkeit und Verzögerung der Kurse hängen von Symbol und Börsenplatz ab.
4. Der Vanguard-Chart nutzt XETR:VWCE. Falls TradingView dieses Symbol nicht auflöst, im Chart-Symbolsuchfeld nach VWCE suchen und den passenden Xetra-Handelsplatz wählen.
5. Die App verbindet sich nicht mit Trade Republic und kann keine Orders platzieren.
6. Die Gewinn-/Verlustberechnung ist manuell: eingezahlter Betrag und aktueller Depotwert eintragen.

Installation auf dem iPhone (nach HTTPS-Veröffentlichung):
- Seite in Safari öffnen
- Teilen antippen
- „Zum Home-Bildschirm“ wählen
- „Als Web-App öffnen“ aktivieren, falls angezeigt
- Hinzufügen

Für eine wirklich automatische Portfolio-Synchronisierung wäre eine unterstützte Broker-Schnittstelle oder ein separater Datenanbieter nötig. Niemals Trade-Republic-Passwort oder TAN in diese Demo eingeben.
